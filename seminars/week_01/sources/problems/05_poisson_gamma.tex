\label{prob:poisson-gamma}
Let $x_1, x_2, \ldots, x_N$ be an independent sample from $\Poiss(\lambda)$.
The prior distribution is the gamma distribution
\[
  p(\lambda) = \Gam(\lambda \mid a, b)
  = \frac{b^a}{\Gamma(a)} \lambda^{a - 1} \exp(-b \lambda),
  \quad a, b > 0.
\]
Find the Bayesian estimate of $\lambda$ as the mean of the posterior
distribution $p(\lambda \mid x_1, \ldots, x_N)$.

\begin{solution}
\solpart{Idea}
Bayes' theorem gives the posterior distribution:
\[
  p(\lambda \mid X)
  = \frac{p(X \mid \lambda) \, p(\lambda)}
         {\int p(X \mid \lambda) \, p(\lambda) \, d\lambda},
  \qquad X = (x_1, \ldots, x_N).
\]
The numerator and the denominator contain the same function. The
denominator only integrates it over $\lambda$. Thus you do not have to
calculate the integral directly:
\begin{enumerate}
  \item Write the numerator as $C \cdot g(\lambda)$. The constant $C$ does
    not depend on $\lambda$.
  \item Find a known distribution $q$ with a density proportional to $g$:
    $g(\lambda) = Z \, q(\lambda)$, where $Z$ is a known constant.
  \item A density integrates to 1. Thus the denominator is
    $\int C Z \, q(\lambda) \, d\lambda = C Z$.
  \item Divide: the posterior distribution is $q$.
\end{enumerate}
The same method gives the posterior mean without a direct integral.

\solpart{Solution}
Let $S = \sum_{i=1}^{N} x_i$.

\solstep{Step 1. Write the numerator as a constant times a function of
  $\lambda$.}
\[
  p(X \mid \lambda) \, p(\lambda)
  = \prod_{i=1}^{N} e^{-\lambda} \frac{\lambda^{x_i}}{x_i!}
    \cdot \frac{b^a}{\Gamma(a)} \lambda^{a-1} e^{-b\lambda}
  = \underbrace{\frac{b^a}{\Gamma(a) \prod_{i} x_i!}}_{C}
    \cdot
    \underbrace{\lambda^{a + S - 1} e^{-(b + N)\lambda}}_{g(\lambda)}.
\]

\solstep{Step 2. Find the distribution with a density proportional to
  $g$.}
Let $a' = a + S$ and $b' = b + N$. The function $g$ has the form of the
gamma density with these parameters:
\[
  g(\lambda) = \lambda^{a' - 1} e^{-b'\lambda}
  = \frac{\Gamma(a')}{b'^{a'}} \, \Gam(\lambda \mid a', b').
\]

\solstep{Step 3. Calculate the denominator.}
The gamma density integrates to 1:
\[
  \int C g(\lambda) \, d\lambda
  = C \frac{\Gamma(a')}{b'^{a'}} \int \Gam(\lambda \mid a', b') \, d\lambda
  = C \frac{\Gamma(a')}{b'^{a'}}.
\]

\solstep{Step 4. Divide the numerator by the denominator.}
The constants cancel:
\[
  p(\lambda \mid X) = \Gam(\lambda \mid a + S, \, b + N).
\]

\solstep{Step 5. Calculate the posterior mean.}
The function $\lambda^{a'} e^{-b'\lambda}$ has the form of the density
$\Gam(\lambda \mid a' + 1, b')$. Thus its integral is
$\Gamma(a' + 1) / b'^{a' + 1}$, and
\[
  \mathbb{E}[\lambda \mid X]
  = \int \lambda \, \Gam(\lambda \mid a', b') \, d\lambda
  = \frac{b'^{a'}}{\Gamma(a')} \int \lambda^{a'} e^{-b'\lambda} \, d\lambda
  = \frac{b'^{a'}}{\Gamma(a')} \cdot \frac{\Gamma(a' + 1)}{b'^{a' + 1}}
  = \frac{a'}{b'}.
\]
The last equality uses $\Gamma(a' + 1) = a' \, \Gamma(a')$. The Bayesian
estimate is
\[
  \hat{\lambda}_{\mathrm{B}} = \frac{a + S}{b + N}.
\]

\solpart{Conclusion}
\begin{itemize}
  \item The gamma prior and the Poisson likelihood give a gamma posterior.
    A prior with this property is \emph{conjugate} to the likelihood. With
    a conjugate prior, the update only changes the parameters:
    $a \to a + S$ and $b \to b + N$. Thus $a$ acts as a prior number of
    events, and $b$ acts as a prior number of observations.
  \item The estimate is a weighted mean of the prior mean $a/b$ and the
    maximum likelihood estimate $\bar{x}$ from
    Problem~\ref{prob:poisson-mle}:
    \[
      \frac{a + S}{b + N}
      = \frac{b}{b + N} \cdot \frac{a}{b}
      + \frac{N}{b + N} \cdot \bar{x}.
    \]
    When $N$ increases, the weight of the data increases, and the estimate
    goes to $\bar{x}$.
  \item When $a \to 0$ and $b \to 0$, the prior density becomes
    proportional to $1/\lambda$. This is the non-informative prior from
    the notes below. With this prior, the Bayesian estimate is equal to
    $\bar{x}$.
\end{itemize}
\end{solution}

\paragraph{Notes on comparing the estimates from
  Problems~\ref{prob:poisson-mle} and~\ref{prob:poisson-gamma}.}
\begin{enumerate}[label=\arabic*.]
  \item For more about non-informative priors, see Section~5.4 ``Priors''
    in Kevin P.\ Murphy, \emph{Machine Learning: A Probabilistic
    Perspective}.
  \item The prior $p(\lambda) \propto \frac{1}{\lambda}$ is a uniform prior
    on $\log \lambda$. To see this, use the change-of-variables rule for
    the density of a function of a random variable. See, for example,
    \href{https://en.wikipedia.org/wiki/Probability_density_function#Function_of_random_variables_and_change_of_variables_in_the_probability_density_function}{this
    article}.
\end{enumerate}
